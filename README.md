# Metta Universal Brand and AI Package

This package helps Metta Welfare Association headquarters, centres, programmes, schools and approved partners create consistent, accessible communications.

## Install the public brand skill

**[Start here: one-link installation and beginner prompt](INSTALL.md)**

In a compatible tool such as Codex, paste:

```text
Install the skill from https://github.com/swc927/metta-universal-brand-ai-package/tree/main/skill/metta-universal-brand . Then use $metta-universal-brand to check setup and guide me one question at a time.
```

[Download skill ZIP](https://github.com/swc927/metta-universal-brand-ai-package/releases/latest/download/metta-universal-brand-skill.zip) · [Download full brand package](https://github.com/swc927/metta-universal-brand-ai-package/releases/latest/download/metta-universal-brand-ai-package.zip)

Ordinary ChatGPT does not install skills from a link; [INSTALL.md](INSTALL.md) gives its reference-file route. This public package contains **no internal employee handbook**.

The package does not replace Management Committee policies or Community Partnership approval. It translates the current approved corporate rules, recent Metta practice and external requirements into reusable guidance for people and AI tools.

## Start here

1. Open [`START_HERE.md`](START_HERE.md) and choose what you want to do.
2. If you are new to AI, copy a guided prompt from [`BEGINNER_PROMPTS.md`](BEGINNER_PROMPTS.md).
3. Use [`EMPLOYEE_QUICK_GUIDE.md`](EMPLOYEE_QUICK_GUIDE.md) for daily work.
4. Consult `METTA_UNIVERSAL_BRAND_GUIDE.md` for the complete standard.
5. Use the examples in `templates/` instead of starting from a blank prompt.
6. Send logo exceptions, partner uses and final public artwork to Community Partnership for approval.

## Package contents

- `METTA_UNIVERSAL_BRAND_GUIDE.md` - canonical human-readable standard.
- `START_HERE.md` - beginner route for common tasks.
- `BEGINNER_PROMPTS.md` - copy-and-paste guided prompts requiring no prompting experience.
- `EMPLOYEE_QUICK_GUIDE.md` - compact daily-use rules and prompt.
- `PLATFORM_SETUP.md` - setup for ChatGPT, Claude, Gemini, Codex and Copilot.
- `AI_PROMPT_PACK.md` - reusable prompts and platform setup instructions.
- `metta-brand-tokens.json` - machine-readable identity and accessibility tokens.
- `templates/` - ready-to-use briefs, prompts and approval checks.
- `SOURCE_REGISTER.md` - evidence, status and unresolved questions.
- `PROJECT_HANDOVER.md` - maintenance and next-action record.
- `CHANGELOG.md` - version history.
- `scripts/validate_package.py` - deterministic package validation.
- `skill/metta-universal-brand/` - self-contained Codex/OpenAI skill.
- `adapters/` - instruction files for other AI assistants.
- `assets/` - approved logo masters copied from the current local Metta master set.

## Authority labels

- **Approved** - explicitly stated in an approved Metta policy or handbook.
- **Verified** - confirmed in a current official Metta source or master asset.
- **Observed** - repeatedly used in current Metta materials but not established as a formal rule.
- **Recommended** - a proposed standard for consistency, accessibility or operational safety.
- **Confirm before use** - incomplete, conflicting or time-sensitive; check with the owner.
