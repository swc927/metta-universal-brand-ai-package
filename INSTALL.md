# Install Metta's public brand skill

This is the public **Metta Universal Brand** skill. It includes brand guidance and official logo assets. The internal employee handbook is not included.

## One link for a compatible skill installer

Copy this complete prompt into Codex or another tool that supports installing skills from GitHub:

```text
Install the Metta Universal Brand skill from https://github.com/swc927/metta-universal-brand-ai-package/tree/main/skill/metta-universal-brand . Install the complete folder, including references and assets. Then use $metta-universal-brand to check that you can read its guide and official logo assets, tell me the guide version and draft status, and ask me one simple question at a time about what I want to create. If this tool cannot install skills, explain that clearly and guide me through using the public brand references instead.
```

The link identifies the exact skill folder. No GitHub invitation is needed for this public repository. Installation still depends on your tool's supported installer and permissions; a link is not an executable installer. Reload or start a new session if your tool requires it to discover newly installed skills.

## Prefer a download?

[Download the brand skill ZIP](https://github.com/swc927/metta-universal-brand-ai-package/releases/latest/download/metta-universal-brand-skill.zip). It contains the complete skill folder. Extract it and ask your compatible assistant to install that folder. Do not install only SKILL.md; the references and assets are required.

## Ordinary ChatGPT or a tool without skill installation

Pasting a GitHub URL or uploading a skill ZIP does not install a persistent skill in ordinary ChatGPT. You can still use the brand guide as reference material.

Download and unzip the [full brand package](https://github.com/swc927/metta-universal-brand-ai-package/releases/latest/download/metta-universal-brand-ai-package.zip), select the guide, source register and beginner prompts together, and upload them to your chat or private project. Add the official logo when needed. Then paste:

```text
Read the attached Metta brand guide, source register and beginner prompts. Tell me which guide version you can access. I am new to AI: ask one simple question at a time and help me create or review Metta communications. Do not invent missing facts or brand rules. My task is: [DESCRIBE IT, OR WRITE I DO NOT KNOW WHERE TO START].
```

Use [PLATFORM_SETUP.md](PLATFORM_SETUP.md) for more platform-specific routes.

## Check setup

Ask: “Can the logo go at the bottom of a poster? What is its minimum printed width? Cite the guide sections.” The answer should cite sections 4.3 and 4.4, explain the conditions for bottom placement and identify the 20 mm printed minimum. It should preserve the guide's draft status and approval labels.

## Later updates

An installed copy does not update automatically. Ask your compatible installer to update from the same skill link, preserving your previous copy outside active skills. Start a fresh session and check the reported version. Keep internal HR documents in the separate private employee package; never add them to this public repository.
