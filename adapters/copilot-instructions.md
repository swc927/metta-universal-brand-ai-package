# GitHub Copilot instructions for Metta projects

- Treat `METTA_UNIVERSAL_BRAND_GUIDE.md` and `metta-brand-tokens.json` as the project’s brand references.
- Use semantic, accessible markup and target WCAG 2.2 AA.
- Reuse the supplied logo asset unchanged; never reconstruct it with HTML, CSS or generated SVG.
- Keep content, contact data, programme facts and translations in controlled data/config files rather than hard-coding unverified values.
- Do not add tracking, external services, production credentials or live integrations without explicit project scope and review.
- Provide tests for forms, keyboard access, validation, language routing and critical links.
